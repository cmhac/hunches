# 02 — Connection layer

Spec: D1, D3, D11, "Authentication", "Managed services" (poolers, TLS), "Errors", Principles (read-only, no secrets).

**Do** in `src/hunches/search.py` (or a clearly named private section of it; no new class hierarchy), small functions only:
- Lazy `import psycopg` with `The pgvector backend needs psycopg: pip install hunches[pg]`; lazy `import boto3` for `rds_iam` with `IAM authentication needs boto3: pip install hunches[rds]`.
- Resolve the URL: `config.pg_url_var` (default `HUNCHES_PG_URL`), environment then keyring (task 01 accessor). Unset: `config.toml: pg_url_var HUNCHES_PG_URL is not set (environment or keyring)`. Missing `pg_table`: `config.toml: pg_table is required for pgvector`.
- `connect(config)` returning an open connection with: read-only (verify the psycopg way: `read_only` on the connection or `SET TRANSACTION READ ONLY`; check docs and use what exists), `prepare_threshold=None`, no autocommit surprises (one explicit transaction for the whole search; verify psycopg's transaction rules in the docs and write down which you used), and `pg_statement_timeout_s` applied with `SET LOCAL statement_timeout` (value passed through, `0` is a real value not "unset", unset issues nothing).
- `rds_iam`: parse host, port, user from the URL; `boto3.Session(profile_name=pg_aws_profile)`, region `pg_aws_region or session.region_name` (error `pg_aws_region is not set and boto3 found no default region`), `client("rds").generate_db_auth_token(DBHostname=, Port=, DBUsername=, Region=)` called immediately before connecting; pass the token as the `password` keyword argument, not inside a URL string; add `sslmode=require` when the URL has no `sslmode`. Verify `generate_db_auth_token`'s signature in the boto3 docs for the installed version. boto3 errors surface as `AWS: <message>`.
- Error scrubber: any exception text shown to the user has the URL, the password and the IAM token replaced with `***`. Append the hints from the spec's Errors table: `rds_iam` authentication failure (the `Check: …` sentence), replica recovery conflict (`Fix: run the search against the primary/writer endpoint …`), statement timeout (`Fix: raise statement_timeout for this role, or set pg_statement_timeout_s in config.toml`), dimension mismatch (`Fix: embedding_model in .hunches/config.toml must be …`). Table/column missing: the Postgres text unchanged.

**Tests (red first, all stubbed)**: each exact message above; env beats keyring; `connect` is called with `prepare_threshold=None` and read-only; `generate_db_auth_token` gets the hand-written host/port/user/region from a sample URL; the token arrives as `password` and not in the URL; `sslmode` defaults to `require` and an existing `sslmode=verify-full` is kept; no-credentials and no-region cases; a stub `connect` that raises an error containing the URL, password and token shows none of them; `pg_statement_timeout_s` = 30 issues `SET LOCAL statement_timeout` with 30, `0` with 0, unset issues none.
