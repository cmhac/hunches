Button. Rare in hunches: keys do the work; buttons live in modals and Setup.

```jsx
<Button variant="success" focused>Approve</Button>
<Button>Cancel</Button>
<Button compact>Run search (r)</Button>
```

- `success` for approve/accept gates, `error` for reject/destructive, `primary` for Save in Setup.
- If a key does the same thing, put it in the label: "Run search (r)".
